# HTML e CSS - Portfólio

Projeto desenvolvido durante as atividades da disciplina de **Back-End**, ministrada pelo professor **João Vitor Yokada**, com o objetivo de aplicar conhecimentos de desenvolvimento web.

## Conteúdos

- Estruturação de páginas com HTML
- Estilização com CSS
- Organização de arquivos
- Utilização de classes e seletores
- Estruturação de layouts
- Personalização de elementos visuais

## Tecnologias utilizadas

- HTML5
- CSS3
